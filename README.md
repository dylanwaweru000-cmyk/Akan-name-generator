#Discover Your Akan Day Name
 
## Description
Discover your traditional Akan day name based on your birthdate and gender


## Features

- Generate Akan names based on birth date.
- Select gender to receive the correct male or female Akan name.
- Display the day of the week the user was born.
- Responsive and user-friendly interface.
- Interactive design with animations.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How It Works

1. The user enters their date of birth.
2. The user selects their gender.
3. JavaScript calculates the day of the week they were born.
4. The application matches the day with the corresponding Akan name.
5. The Akan name and birth day are displayed.
